# AGENTS.md

## Commits

- Nach jedem abgeschlossenen Arbeitsschritt einen eigenen Commit anlegen, nicht mehrere Schritte
  sammeln.
- Ein Commit enthält nur die Änderungen dieses Schritts. Fremde oder unfertige Änderungen im
  Arbeitsverzeichnis bleiben unberührt.
- Commit-Nachrichten auf Deutsch, mit der Übung vorangestellt, z. B.
  `Übung 4.1: Teststrategie in Implementierungsstrategie klargestellt`.
